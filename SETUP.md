# Mayur's GitHub profile README

## Files

- `README.md` — profile page content. Put this at the root of the repository named `Mayur-666`.
- `.github/workflows/snake.yml` — generates the contribution snake and publishes it to the `output` branch.

## Install

1. Open `https://github.com/Mayur-666/Mayur-666`.
2. Replace the repository's `README.md` with the supplied `README.md`.
3. Add `.github/workflows/snake.yml` at the exact path shown.
4. Commit both files to the `main` branch.
5. Open the repository's **Actions** tab.
6. Run **Generate contribution snake** using **Run workflow**.
7. After it succeeds, check that the `output` branch contains:
   - `github-contribution-grid-snake.svg`
   - `github-contribution-grid-snake-dark.svg`

The README references the dark SVG on the `output` branch.

## If the snake workflow fails

In the repository, open **Settings → Actions → General → Workflow permissions** and enable **Read and write permissions**. Save, then run the workflow again.

## Notes

- The snake is generated from GitHub's public contribution graph; it does not update until the workflow runs.
- GitHub Actions scheduled workflows can be delayed. Use **Run workflow** for an immediate refresh.
- GitHub README pages do not execute JavaScript. Dynamic-looking elements are images generated by external services.
- The telemetry section uses GitHub-hosted profile links and does not depend on third-party stats services.
- The project names and summaries in the README are starter copy. Verify each description and link against the current portfolio before publishing.
